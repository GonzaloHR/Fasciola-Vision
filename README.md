# Fasciola-Vision

Fasciolisis Diagnostic.

Next.js (App Router) + TypeScript + Tailwind CSS v4.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Paleta en `app/globals.css` (bloque `@theme`). Los formularios de `components/login-form.tsx` y
`components/register-form.tsx` validan en el cliente pero no tienen backend: buscá los `TODO` para conectar
Auth.js o Supabase Auth.

# FasciolaVision

Hackathon concept exploring a microscope clip-on and computer vision to study
`Fasciola hepatica` and similar-looking eggs. The site includes the project's
85-second pitch video and a conceptual, non-diagnostic field illustration.

## Run locally

```sh
npm install
npm run dev
npm run build && npm start
```

The supplied project pitch is served from `public/fasciola-hackathon.mp4`.

## Project status

This is a presentation prototype. The site does not include a working image
detector, classifier, account system, or clinically validated diagnostic
workflow. Illustrations are schematic and must not be used to make health
decisions.
